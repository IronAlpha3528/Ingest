## Summary
An architectural pattern that isolates pure business logic in an immutable core while confining side effects and I/O to outer boundaries. Pure functions make domain rules easy to reason about and fast to test without mocks. Shell components orchestrate dependencies and adapt external services.

## Key points
- An architectural pattern that isolates pure business logic in an immutable core while confining side effects and I/O to outer boundaries.
- Pure functions make domain rules easy to reason about and fast to test without mocks.
- Shell components orchestrate dependencies and adapt external services.
